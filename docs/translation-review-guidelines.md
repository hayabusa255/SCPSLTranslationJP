# 翻訳レビューの方針

日本語訳を全件レビューするときの方針です。

- 対象は SCP: Secret Laboratory の UI・字幕・ボイスラインです。設定項目と「する/しない」のような選択肢など、前後の行とセットで読んでください。
- 重大度
  - CRITICAL: 意味が違う、別の行の訳が入っている（行ずれ）、訳抜け。
  - WARNING: 語の選択（例: 作画→描画）、不自然・ぎこちない表現。
- 口調: 遊び心のある砕けた訳は意図的なことがあります。意味や機能が伝わるなら、口調だけでは指摘しないでください。
- ボイスライン（SCP127VoiceLines など）は意訳・言葉遊びを許容します。
- Northwood、SCP 番号などの固有名詞は原文どおりにします。
- 指摘文は日本語で簡潔に書き、行番号や ID には触れず、該当箇所の語句を引用してください。
